# GlassMind

**An educational AI project written in pure JavaScript that runs locally, learns words, builds a knowledge graph, and generates sentences.**

GlassMind is an open-source project designed to demonstrate how a simple language model can be built from scratch using only HTML, CSS, and JavaScript.

Unlike modern cloud-based AI systems, GlassMind runs entirely on your computer and does not rely on external APIs or machine learning libraries. Its purpose is to help developers and curious learners understand the fundamental ideas behind language models in a simple, readable, and educational way.

## Features

- Learns new words and sentences
- Builds a vocabulary over time
- Stores relationships between words as a knowledge graph
- Generates simple sentences from learned data
- Saves and loads its knowledge
- Runs completely locally
- Written in pure JavaScript
- Designed for learning and experimentation

## Project Goals

GlassMind is **not** intended to compete with large language models.

Instead, its goal is to explain the ideas behind language learning and sentence generation through clean, understandable code that anyone can explore and modify.
